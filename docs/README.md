Application and project documentation for Lucid. Community, legal, and meta files
(README, LICENSE, CHANGELOG, CONTRIBUTING, THIRD-PARTY-NOTICES) live in the
repository root by convention; everything else lives here.

| Document | What it covers |
| :------- | :------------- |

| [Engineering_Showcase.md](Engineering_Showcase.md) | Engineering/architecture showcase for the app. |
| [document-safety.md](document-safety.md) | Saving, recovery, tabs, and sidebar behavior in the pending 1.0.8 candidate. |
| [releases/1.0.8.md](releases/1.0.8.md) | Prepared release notes; not yet published. |
| [releases/1.0.8-qualification.md](releases/1.0.8-qualification.md) | Developer verification evidence and publication gates. |
| [Sample.md](Sample.md) | Sample Markdown document for exercising the reader. |
