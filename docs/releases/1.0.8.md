# Lucid 1.0.8 — prepared stable release notes

Candidate build: **9**. Status: **unpublished, awaiting qualification**.
The release date and final download are assigned only after qualification passes.

Lucid 1.0.8 improves reliability when working across tabs and windows, saving moved files,
recovering interrupted sessions, and navigating documents with local images.

- Editing and Undo/Redo stay with the displayed tab, including rapid tab changes.
- Recovery retains unsaved edits in named files and separate windows, including drafts whose
  original file disappeared. Opening another file at launch preserves pending recovery.
- Cancelling close or quit keeps every tab available. Failed saves preserve unsaved text,
  and discard decisions take effect only when the complete review succeeds.
- Save follows same-volume file moves instead of recreating an abandoned filename. If the
  original file cannot be identified, Lucid asks you to choose a destination.
- Saving and immediately continuing to type no longer causes a false external-change alert.
- Local images refresh when switching documents, returning to replaced assets, or revealing
  the preview, including documents with identical Markdown in different folders.
- Smoother sidebar toggles and resizing preserve filter text, editor focus, reading position,
  and find matches. Open windows resize their sidebars independently.
- Native popovers use consistent surfaces, and motion respects accessibility preferences.

Declared target: macOS 14.0 or later, Apple Silicon (arm64). Older-OS runtime qualification
is pending; the current candidate has been exercised on macOS 27.0.1.
Recovery snapshots are coalesced and do not guarantee recovery of every last keystroke
after immediate process termination or power loss.

The available download remains [1.0.7 Public Beta](https://github.com/ajayuhjain89/lucid-macos/releases/tag/v1.0.7).
